# How to operate the NRB Report Dashboard — video script (trial phase)

Narration for `how_to_operate_trial.mp4` (~3½ min). Also usable as a printed
quick-start handout or WhatsApp text for the team.

## Intro
Daily reporting does **not** change — keep submitting the daily Google Form
exactly as before. The dashboard picks up every submission automatically.

## Step 1 — Live Dashboard
Open the app any time to see totals for any date range: IDs captured, IDs
distributed, birth and death certificate applications. Use the date-range
filter on the left; press **Refresh data now** for the very latest
submissions. Tabs: trends over time, section activity, field-by-field
breakdown.

## Step 2 — Compliance
Who reported what. Each row is a day, each column a section — green means a
report came in, red means nothing was submitted. The **People** tab shows each
person's submissions; **Scheduled vs reported** compares the work schedule
against what actually came in.

## Step 3 — Data Quality
The system flags problems automatically: duplicate submissions (latest copy
kept), names that don't match the staff list, future dates, possible double
counting. Check it now and then during the trial and report anything odd.

## Step 4 — Monthly Report
Replaces the old month-end routine. Pick a month, check the preview, log in,
click **Download Excel report**. Weeks are derived automatically (Mon–Sun,
month days only); the file is values-only, formatted, and named correctly.

## Step 5 — Scheduling (admins)
Mark who is away → **Generate fair allocation** → the system rotates people
through teams fairly using past weeks' history. Adjust manually, save the
week, copy the ready-made WhatsApp message. Teams are managed under
**Manage teams** (create, edit, remove, pin fixed members).

## Step 6 — Admin
Data source link, staff roster (must match the form's Name list), report
layout, user accounts, and **Backup**. During the trial, download a database
backup after making changes — free hosting resets its storage on redeploys.
